Design Guidelines

Clear rules for maintaining brand consistency across all surfaces. Follow these strictly to preserve the institutional, data-first aesthetic.

Do
  • Use flat solid backgrounds from the tonal layering system
  • Maintain generous whitespace between sections (80px desktop)
  • Use pill-shaped buttons for all primary calls to action
  • Apply signal colors exclusively for data values (green/red/amber)
  • Use Inter everywhere -- headings, body, labels, data
  • Express elevation through background color, not shadows
  • Write confident, data-driven copy that respects intelligence
  • Use JetBrains Mono for tabular financial data alignment
  • Keep the 8px grid for all spacing decisions
  • Use the frosted glass nav bar pattern (blur + transparency)
Do Not
  • Use gradients on backgrounds -- solid colors only
  • Use emojis anywhere in the UI or marketing copy
  • Use playful illustrations or cartoon art
  • Use generic stock photos of people shaking hands
  • Use rounded-full avatars as decorative elements
  • Use Lucide icons as decorative filler -- icons must be functional
  • Use casual greetings like "Hey!" or "Welcome back!"
  • Apply excessive drop shadows -- only on interactive elements
  • Use bright lime, yellow, or orange as accent colors
  • Mix typefaces -- Inter is the only UI font
